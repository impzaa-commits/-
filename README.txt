ฝนมาไหม — เวอร์ชันเพิ่มช่องพายุฝนฟ้าคะนอง

เพิ่ม:
- โอกาสฝนสูงสุด
- โอกาสพายุฝนฟ้าคะนอง
- CAPE สูงสุด
- ฝนรวม 2 ชั่วโมง
- ลมกระโชก
- ประเมินใหม่ทุก 10 นาที
- วัดสถานีวัดระดับน้ำ ใกล้ที่สุด
- ในประเทศและนอกประเทศ
- เพิ่มหยดน้ำ ระดับ เขียว ระดับน้ำต่ำสุด เหลือง ระดับน้ำเพิ่มขึ้นมา ส้ม ระดับน้ำเริ่มจะเข้าเขตท่วม แดง น้ำน่าจะสูงเกินระดับการวัด

หมายเหตุ:
ค่า “โอกาสพายุฝนฟ้าคะนอง” เป็นดัชนีประเมินของแอปจาก CAPE + โอกาสฝน + ลมกระโชก + weather code
ไม่ใช่เปอร์เซ็นต์เตือนภัยทางการจากกรมอุตุนิยมวิทยา
