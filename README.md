# 🌧️ ฝนมาไหม

เว็บช่วยดูเรดาร์ฝน พยากรณ์ระยะสั้น ระดับน้ำใกล้เคียง และเส้นทางหลบพายุเบื้องต้น สำหรับใช้งานบนโทรศัพท์และคอมพิวเตอร์

เว็บไซต์: <https://impzaa-commits.github.io/-/>

> [!WARNING]
> หน้านี้เป็นเครื่องมือช่วยตัดสินใจ ไม่ใช่ประกาศเตือนภัยหรือคำสั่งอพยพจากหน่วยงานรัฐ หากมีประกาศทางการ ให้ปฏิบัติตามประกาศนั้นก่อนเสมอ

## สิ่งที่มีในระบบ

- **เรดาร์ฝนย้อนหลัง** — เล่นภาพการเคลื่อนตัวของฝนย้อนหลังจาก RainViewer
- **ประเมินฝนและพายุระยะสั้น** — แสดงโอกาสฝน ฝนสะสม ลมกระโชก CAPE และคะแนนโอกาสพายุจาก Open-Meteo
- **เลือกตำแหน่งเอง** — คลิกเลือกจุดบนแผนที่ กรอกละติจูด/ลองจิจูด หรือเลือกพิษณุโลก เหมาะกับคอมพิวเตอร์ที่ไม่มี GPS หรือหา GPS ผิด
- **จำพิกัดที่เลือก** — จุดที่เลือกจะใช้ร่วมกันกับเรดาร์ พยากรณ์ ระดับน้ำ และหน้า “ทางหนีพายุ” แม้รีเฟรชหน้า
- **ระดับน้ำสถานีใกล้เคียง** — แสดงระดับน้ำ แนวโน้ม เวลาอ่านค่า และสีหยดน้ำเทียบระดับตลิ่งของสถานีจาก ThaiWater
- **แก้ปัญหา HTTP 429** — ผู้ชมเว็บอ่านข้อมูลชุดกลาง `water-level.json` แทนการเรียก ThaiWater จากทุกเครื่องพร้อมกัน
- **ทางหนีพายุ** — ประเมินทิศลมและความเสี่ยง แล้วหาเส้นทางถนนเบื้องต้นด้วย OSRM

## ใช้ตำแหน่งอย่างไร

### โทรศัพท์

กดอนุญาตตำแหน่งในเบราว์เซอร์ แล้วกด **ตำแหน่งฉัน** เพื่อใช้ GPS ของอุปกรณ์

### คอมพิวเตอร์ที่ไม่มี GPS หรือพิกัดเพี้ยน

1. กด **เลือกจุดบนแผนที่** แล้วคลิกจุดที่ต้องการ
2. หรือกรอก **ละติจูด** และ **ลองจิจูด** แล้วกด **ใช้พิกัดนี้**
3. หรือกด **ใช้พิษณุโลก**

พิกัดที่เลือกจะถูกจำในเบราว์เซอร์เครื่องนั้น และเมื่อกด **ทางหนีพายุ** หน้าหลบพายุจะรับพิกัดเดียวกันทันที

> ปุ่ม **ใช้ GPS ของอุปกรณ์** ในหน้าหลบพายุ มีไว้เมื่ออยากเปลี่ยนไปใช้ GPS จริง ๆ เท่านั้น เพราะคอมพิวเตอร์บางเครื่องอาจระบุตำแหน่งจาก Wi‑Fi ผิดจังหวัดได้

## การอัปเดตข้อมูลระดับน้ำอัตโนมัติ

GitHub Actions ชื่อ **Publish site with water data** จะทำงานเมื่อมีการแก้ไฟล์, กดสั่งเอง หรือทุกชั่วโมงที่นาที **17** และ **47** โดยจะ:

1. ดึงข้อมูลสถานีจาก ThaiWater เพียงครั้งเดียว
2. บันทึกเป็น `water-level.json`
3. เก็บข้อมูลชุดก่อนหน้าไว้ หากต้นทางตอบช้า/ตอบ `HTTP 429`
4. เผยแพร่หน้าเว็บใหม่ผ่าน GitHub Pages

หน้าเว็บจะไม่ใช้ข้อมูลสถานีที่เก่ากว่า 3 ชั่วโมงเป็นสถานะน้ำปัจจุบัน

### สั่งอัปเดตเอง

ไปที่แท็บ **Actions** → **Publish site with water data** → **Run workflow** → เลือก `main` → **Run workflow**

## แหล่งข้อมูล

- แผนที่ฐาน: OpenFreeMap / MapLibre
- เรดาร์ฝนย้อนหลัง: RainViewer
- พยากรณ์ฝน ลม และ CAPE: Open-Meteo
- ระดับน้ำสถานี: ThaiWater / สสน.
- ข้อมูลลำน้ำของหน้าหลบพายุ: Open-Meteo Flood / GloFAS
- เส้นทางถนน: OSRM / OpenStreetMap

## ข้อจำกัดสำคัญ

- เรดาร์ RainViewer ที่ใช้เป็น **ภาพย้อนหลัง** ไม่ใช่ภาพอนาคต
- คะแนน “โอกาสพายุฝนฟ้าคะนอง” เป็นคะแนนที่คำนวณจากแบบจำลอง ไม่ใช่เปอร์เซ็นต์เตือนภัยทางการ
- ระดับน้ำคือข้อมูลจาก **สถานีวัด** ไม่ใช่ความลึกของน้ำบนถนนหรือหน้าบ้าน
- หน้า “ทางหนีพายุ” เป็นเวอร์ชันต้นแบบ ยังไม่ยืนยันถนนน้ำท่วม สภาพถนนจริง จุดอพยพ หรือความปลอดภัยของปลายทาง
- การใช้พิกัดต้องเปิดเว็บผ่าน HTTPS เช่น GitHub Pages; การเปิดไฟล์โดยตรงแบบ `file://` อาจใช้ GPS ไม่ได้

## อัปเดตไฟล์ขึ้น GitHub

อัปโหลด `index.html`, `storm-escape.html`, `water-level.json` และโฟลเดอร์ `.github/workflows/water-pages.yml` ไว้ในรีโปเดียวกัน โดย `index.html` และ `storm-escape.html` ต้องอยู่ระดับบนสุดของรีโป

หากแก้ไฟล์แล้วหน้าเว็บยังเหมือนเดิม ให้กด **Ctrl + F5** เพื่อรีเฟรชไฟล์เก่าที่เบราว์เซอร์จำไว้
