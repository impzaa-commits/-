สถานะน้ำ: ไทย—ThaiWater / ฝรั่งเศส—Hub’Eau + Vigicrues / UAE—Open‑Meteo Flood (GloFAS)
พายุฝนฟ้าคะนอง: ประเมินจาก CAPE + โอกาสฝน + ลมกระโชก + weather code
การประเมินนี้เป็นตัวช่วยตัดสินใจ ไม่ใช่ประกาศเตือนภัยทางการ • ฝรั่งเศสใช้ระดับน้ำ Hub’Eau และระดับเฝ้าระวัง Vigicrues • UAE ใช้แบบจำลอง GloFAS + พยากรณ์ฝน ไม่ใช่สถานีวัดน้ำจริง • ค่า “โอกาสพายุฝนฟ้าคะนอง” เป็นคะแนนประเมินจากแบบจำลอง ไม่ใช่เปอร์เซ็นต์เตือนภัยทางการ • เรดาร์ RainViewer รุ่นฟรีแสดงข้อมูลย้อนหลัง ไม่ใช่ภาพเรดาร์อนาคต
